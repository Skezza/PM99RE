# Experiments

Use this directory for source-only prototypes that may become tools later.

Keep runtime payloads, proprietary game assets, generated disks, emulator images,
large screenshots, and temporary outputs in ignored local roots such as `.local/`,
`work/`, `artifacts/`, or a tool-specific `.local/` directory.

Use `worktrees/` for alternate checkouts and worker branches. Do not place ad hoc
runner, editor, or patcher checkouts under `upstream/`; that directory is only for
declared submodules.
