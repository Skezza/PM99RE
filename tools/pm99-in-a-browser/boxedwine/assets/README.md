# Local Asset Slots

Everything below this directory is for local runtime inputs and is ignored by
git except placeholder files.

```text
rootfs/     BoxedWine-compatible Wine root zip.
apps/       PM99 application zip produced from an owned local install.
overlays/   Optional override zips, such as DirectDraw experiments.
```

Do not commit proprietary PM99 binaries, PM99 data files, Wine filesystems, or
downloaded BoxedWine/vendor assets.
