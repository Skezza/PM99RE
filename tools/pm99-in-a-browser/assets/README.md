# Local Assets

Ignored local runtime assets go here.

Expected generated files:

- `pm99/`: symlink or copy of the local isolated PM99 fixture
- `pm99.zip`: PM99 fixture zipped for Wine/BoxedWine mounting experiments
- `pm99.iso`: optional ISO image for v86 CD-ROM mounting
- `pm99-manifest.json`: generated hash/size summary for required PM99 files
- `v86/`: BIOS, VGA BIOS, and Windows disk images supplied locally
- `boxedwine/`: optional BoxedWine package/config assets supplied locally

Nothing in this directory should be committed except this README.
